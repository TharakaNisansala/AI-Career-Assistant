# System Requirements

## Functional Requirements

## User Management

The system should allow users to:

- Register an account
- Login securely
- Manage profile information
- View previous analyses



## Resume Management

Users should be able to:

- Upload resume files
- Upload PDF/DOCX formats
- View uploaded resumes
- Delete resumes
- Maintain resume history



## Resume Analysis

The system should:

- Extract resume information
- Analyze skills
- Identify education details
- Analyze work experience
- Generate ATS score
- Provide improvement suggestions



## Job Matching

The system should:

- Accept job descriptions
- Compare resume with job requirements
- Calculate matching percentage
- Identify missing skills
- Recommend improvements



## Interview Preparation

The system should:

- Generate technical questions
- Generate HR questions
- Provide interview guidance
- Evaluate answers



# Non Functional Requirements

## Performance

- System should provide analysis results within acceptable time
- Support multiple users

## Security

- User data should be protected
- Authentication should be implemented

## Scalability

- System architecture should support future expansion

## Usability

- Interface should be simple and user-friendly

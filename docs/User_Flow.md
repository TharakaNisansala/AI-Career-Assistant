# User Flow

## New User Flow

1. User opens application
2. Creates account
3. Logs into system
4. Uploads resume
5. Adds target job description
6. Starts AI analysis
7. Receives ATS score
8. Views improvement suggestions
9. Saves analysis results




## AI Analysis Flow

    Resume Upload
        ↓
    Extract Text
        ↓
    Process Resume Information
        ↓
    Send Data To AI Model
        ↓
    Generate Analysis
        ↓
    Store Results
        ↓
    Display Dashboard
